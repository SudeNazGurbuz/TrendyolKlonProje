# Trendyol Klon Projesi

HTML, CSS ve JavaScript kullanılarak hazırlanmış Trendyol arayüzü deneme projesi.

## Özellikler

- Ana sayfa ve ürün listeleme
- Sepet, giriş/kayıt, hakkımızda ve iletişim sayfaları
- Projede kullanılan görseller

## Çalıştırma

`index.html` dosyasını tarayıcıda açın. İsterseniz VS Code Live Server eklentisini kullanabilirsiniz.

> Bu proje eğitim amaçlı bir arayüz çalışmasıdır; Trendyol'un resmî ürünü değildir.
